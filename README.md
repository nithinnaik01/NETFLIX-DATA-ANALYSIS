# NETFLIX-DATA-ANALYSIS
# 🎬 Project 2: Netflix Content Strategy Analysis

## How to Run

### Step 1: Install libraries
```
pip install -r requirements.txt
```

### Step 2: Generate the dataset
```
python generate_netflix_data.py
```

### Step 3: Run the analysis
```
python netflix_analysis.py
```

## What this project does
- Loads 8000+ Netflix titles
- Cleans and processes data
- Runs SQL queries (SQLite) for aggregations
- Analyzes genres, countries, ratings, growth trends
- Creates a Netflix-themed dashboard

## Output Files
- `netflix_data.csv` - Generated dataset
- `netflix_dashboard.png` - Full visual dashboard
